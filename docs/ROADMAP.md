# Roadmap

These are proposals, not implemented features or scheduled commitments.

## Pilot preparation

- Select a software license and a responsible project owner.
- Agree authorship, independent review, original-document authority, and how
  reviewed versions are retained with the participating municipality.
- Test the format on several public proposals across two or three meetings.
- Evaluate required editing time, projector readability, and public understanding.
- Confirm browser compatibility and perform an accessibility review.

## Candidate improvements after the pilot

- Explicit human review metadata and a controlled revision/approval workflow.
- More precise presentation summaries without losing caveats or source context.
- Multi-year financial schedules and additional statement-level source references.
- Additional print engines/formats if browser printing proves insufficient.
- Migration support when introducing a new document schema version.
- Optional links to existing information-portal topics through stable identifiers.

## Separate architecture decisions

Shared editing, server persistence, accounts, confidential material, automated
source ingestion, and AI-assisted text require separate decisions. None is an
implicit part of the current foundation.
